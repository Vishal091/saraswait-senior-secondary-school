# Saraswati Senior Secondary School — Bilaspur

A responsive, multi-page school website starter for Saraswati Senior Secondary School, Bilaspur, Yamunanagar, Haryana.

## Pages
- `index.html` — Home
- `about.html` — School profile and principal's message
- `academics.html` — Academic stages and learning approach
- `admissions.html` — Admissions overview and inquiry form
- `campus-life.html` — Activities, clubs, and student life
- `news.html` — School news and updates
- `contact.html` — Location and contact form

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server. No build step or package installation is required.

## Before launch
- Confirm board/affiliation details and current admission policies with the school office.
- Add official contact number, email, office hours, fee information, and current notices.
- Replace the illustrative stock photos with school-owned photographs.
- Connect the inquiry forms to an approved email service or backend; the current forms are front-end demos and do not transmit submissions.
- Confirm all facilities, academic details, and official branding before publishing.

The site uses plain HTML, CSS, and JavaScript and can be hosted on GitHub Pages.
