# Saraswati Senior Secondary School — Bilaspur

A responsive, multi-page website preview for Saraswati Senior Secondary School, Bilaspur, Yamunanagar, Haryana.

## Pages
- `index.html` — Home
- `about.html` — School profile and principal
- `academics.html` — Learning stages and academic overview
- `admissions.html` — Admissions overview and inquiry form
- `campus-life.html` — Student activities and gallery
- `news.html` — Published science-competition story and future news slots
- `contact.html` — Location, map and contact form

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server. No build step or package installation is required.

## Built with
- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- Custom SVG school mark and favicon

## Before launch
- Confirm the correct official school name, board/affiliation, academic details, policies and admission process.
- Add verified telephone number, email, office hours, fee information and current notices.
- Replace illustrative Unsplash photographs with school-owned and approved photographs.
- Connect both enquiry forms to an approved email service or backend. Current forms are non-transmitting front-end previews.
- Verify the map pin/address and obtain approval for the logo, photographs, and published text.
- Add any official accessibility, privacy, and child-safeguarding statements required by the school.
